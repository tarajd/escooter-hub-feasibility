# escooter-hub-feasibility
Eugene, Oregon E-Scooter Hub Location Identification report and map
<br><br>

Identifying suitable locations for e-scooter hubs in Eugene, Oregon utilizing population density, residency, business, and workplace points, and bikeway and crosswalk data layers to identify where highest levels of demand exist. <br>
Used ESRI's ArcGIS Pro to synthesize layers down to a final map.
